Pysar.Design

A visual designer for .rxaml reports

Drag, drop and preview bands, repeaters and bindings on a real paginated canvas — the same layout SkiaReportRenderer produces at build time, without leaving your IDE.

Pysar.Design is available for Rider. It's a paid plugin with a 30-day trial on the JetBrains Marketplace, and requires the free Pysar language plugin. Visual Studio and VS Code builds are still in development. Syntax highlighting stays free regardless.
